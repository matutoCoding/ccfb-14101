# 读码相机成像仿真系统

面向快递交叉带分拣中心的浏览器端读码相机成像仿真。在方案设计阶段即可确定相机选型、安装位置与光源打法，
减少现场 1–2 周的读码率调试。TypeScript + WebGL2 技术栈，包裹样本与方案均存浏览器 IndexedDB，
批量仿真在 Web Worker 中运行并支持断点续跑。

## 五个页面

| 页面 | 能力 |
| --- | --- |
| 包裹样本 | 纸箱/编织袋/塑料快递袋/软包按比例生成；尺寸分布可调；面单位置、倾斜、褶皱鼓包程序化随机；样本入库 IndexedDB |
| 相机光源 | 面阵/线阵相机、镜头焦距/光圈/景深、液态镜头对焦延迟、触发模式、曝光；条形光/同轴光角度强度；实时景深/视场/像素分辨率 |
| 安装布局 | 龙门架顶扫+左右侧扫，俯视/侧视画布画 FOV 覆盖，样本驱动的覆盖率与死角统计 |
| 成像仿真 | 按皮带速度连续过包，每相机实时灰度图，模块像素/对比度/噪声可见，一维码 Code128 与二维码 QR 均覆盖 |
| 读码统计 | 一键批量重跑（Worker 不卡界面、断点续跑）；按包裹类型与相机统计读码率；失败按模糊/反光/出视场/分辨率不够归类；两套布局同批包裹 A/B 对比 |

## 核心物理模型

- **线阵触发几何**（`src/sim/lineScan.ts`）
  - 编码器模式：行 i 固定对应位移 `i·mmPerLine`，与速度无关。1 行/mm 时 100mm 面单恒为 100 行，变速只改触发时刻。
  - 自由运行：按固定行频推进时间，位移由皮带运动学积分。速度变大每行覆盖物理距离变长，图像纵向拉伸。
  - 验收测试 `src/sim/acceptance.test.ts`：1.8m/s 与 2.5m/s 下编码器均严格 100 行；freerun 2.5m/s 为 72 行、误差 ≤1 行。
- **皮带运动学**（`belt.ts`）：分段线性速度曲线，位移解析积分、时间反解逐段推进，支持变速。
- **镜头景深**（`optics.ts`）：薄透镜超焦距/近远限、离焦弥散圆；液态镜头按测高光幕+对焦延迟选对焦面。
- **运动模糊**：面阵按曝光窗口拖影；线阵编码器模式几何由触发吸收，freerun 按行频失配计算。
- **光源与反光**（`lighting.ts`）：Phong 着色，塑料/覆膜低粗糙度产生集中镜面反射斑，光斑位置随光源角度移动，覆盖率在条码区采样统计。
- **成像渲染**（`render.ts`）：逆映射光栅化；线阵输出做纵向物理尺度方形化，保证条码模块纵横像素一致、可被解码库识别。
- **条码**（`barcode.ts`）：自带 Code128-B 编码器（模式表取自 zxing 官方 reader），QR 用 zxing 编码；解码统一走 zxing。

## 仿真可信度说明

读码率结果由可复现的物理链路驱动：确定性 Rng（同种子同结果）→ 包裹几何 → 相机投影/景深/模糊/反光
→ 灰度渲染 → zxing 真实解码 → 失败归类。模块像素、对比度等指标与实际渲染图严格对齐，
分辨率不足、景深外模糊、镜面反光盖码等现象都能追溯到具体物理参数。
